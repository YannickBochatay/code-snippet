Code snippet

Web component for code snippets based on highlightjs.

Github

Installation

<script src="https://cdn.jsdelivr.net/npm/code-snippet-wc" type="module" ></script>

Usage

Basic

<code-snippet>console.log("Hello world");</code-snippet>

Language

You can specify the language. Default is automatic detection.

<code-snippet language="js">console.log("Hello world");</code-snippet>

Theme

You can specify the theme. It will load dynamically.

<code-snippet theme="arta">console.log("Hello world");</code-snippet>
